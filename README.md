# sc-corpus lung report

Live status of the human **lung** single-cell & spatial corpus assembled with
[sc-omics-retriever](https://github.com/rkrubens/sc-omics-retriever): healthy adult lung, non-infectious lung
diseases, all lung cancers (NSCLC, SCLC, …, incl. metastases and pleural mesothelioma) and lung transplantation.

**View:** https://rkrubens.github.io/sc-corpus-lung-report/ · **Metadata provenance per dataset:** https://rkrubens.github.io/sc-corpus-lung-report/evidence/

Regenerated with `corpus.py report` after every corpus update; this repository holds only the latest snapshot.
